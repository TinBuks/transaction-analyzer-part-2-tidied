The follow up project to transaction analyzer part 1. Mostly the same code but with the option for user input to choose which function to run. I also personally included a rounding feature to the Averages as it doesn't make much sense for money to have 20 decimal places.

I plan to revisit this project and add in a way for the user to easily add new items to their transaction list. I feel like I could actually benefit from using this application as it would force me to see what and where my actual spending goes to.
